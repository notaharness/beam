Passkey compatibility



beam needs WebAuthn PRF to derive its encrypted directory key. Your browser and passkey provider must support it.


This page also needs X25519 in Web Crypto: Safari 18.4+, Chrome 133+, or Firefox 130+. Passkey PRF support is a separate requirement.


This is what vendors document, not a matrix beam has tested end to end. The browser’s encryption support and the passkey provider’s PRF support are separate requirements; unsupported or unverified combinations are not promised to work.



Safari
For this page use Safari 18.4 or later. Safari 18.0 PRF support alone is insufficient.


Apple Passwords, iCloud Keychain
Use updated Apple software. iOS/iPadOS 18.4+ with Safari 18.4+ is the page’s practical baseline; macOS Safari 18.4+ also needs a compatible provider. Unverified: the oldest supported macOS and provider pairing, and whether Apple’s fix for PRF over a phone (hybrid) has shipped.


Firefox
Firefox 139+ on desktop has the browser features. Your passkey provider must still supply PRF. Firefox 130 alone is not enough to promise PRF. Unverified: Firefox on Android and iOS.


Chrome
Chrome 133+ meets the encryption baseline. PRF must still be confirmed for your provider. Unverified: the first Chrome release with PRF, and Google Password Manager’s PRF support by operating system and version.


1Password for iOS
1Password for iOS 8.10.74+ adds provider PRF support on iOS 18. This page also needs Safari/iOS 18.4+ for X25519.


1Password browser extension (beta 2.26.1), Android (beta 8.10.38)
PRF was introduced in these beta versions; earliest stable versions are unverified here. Update your provider and use the result check.


Security keys, YubiKey
Use a PRF-capable FIDO2 key with a browser/OS that exposes it. A key supporting hmac-secret alone does not guarantee WebAuthn PRF. Unverified: firmware and operating system minimums.


Windows Hello
Unverified. Browser support does not imply Windows Hello support.


Bitwarden, Proton Pass, other providers
Unverified. A provider that unlocks its own vault with PRF may still not return PRF for beam’s passkey.


Edge, Samsung Internet
Unverified. Chrome’s version numbers do not carry over; this page checks at runtime.
